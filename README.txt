Mystic Spells｜あなたに似合う魔法診断

ファイル構成
- index.html : サイト本体
- style.css  : デザイン・レスポンシブ対応
- app.js     : 認証画面、15問診断、結果表示、カードPNG保存、肖像画プロンプト生成
- assets/    : 公式ロゴ、3商品画像、肖像画サンプル

プレビュー
index.html をブラウザで開いてください。Google Fontsの読み込みにはインターネット接続が必要ですが、基本機能はローカルでも動作します。

無料公開について
このフォルダを静的サイト対応のホスティングサービスにアップロードできます。
重要：現在の4桁認証はブラウザ側で動作する簡易ゲートです。パスワードはJavaScript内に含まれるため、URLを知る人以外に見せないための本格的なアクセス制御にはなりません。招待者限定で実際に保護する場合は、ホスティング側のアクセス制御やサーバー側認証を設定してください。

診断は娯楽目的です。医学的・心理学的な診断ではありません。
